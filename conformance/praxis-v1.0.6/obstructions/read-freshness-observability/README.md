# Read-freshness observability correction

Praxis v1.0.5 instructed a stateless model to perform a fresh check and a fresh read before revising an already changed path, but its Memory and DecisionView retained only the current document snapshot. Reading unchanged bytes therefore upserted the same snapshot and produced no semantic state change. The executable reproducer authenticates that failed representation directly from immutable tag `v1.0.5`; private Poiesis run evidence separately witnessed the resulting repeated-read fixed point.

v1.0.6 adds one typed `ReadEvidence` value owned by the EpistemicStrategy. Every `read_file` observation records the exact path plus the current test and conflict epochs, and DecisionView exposes that witness. Pre-effect replacement admission requires a previously changed path to match the latest read path and current epochs. A new full check makes earlier read evidence stale. Every replacement conflict monotonically advances the global conflict epoch; after the first conflict, every replacement requires an exact-path read at the latest epoch, so multiple unresolved conflicts cannot erase one another. The model-visible instructions name the exact witness and direct the model to stop rereading once it is current. The implementation lowering identity advances to `agent.epistemics.praxis-zig-working-set.lowering.v2`.

This changes the parent application ID, WASM, Decision Contract, codec, and Machine state schema. It does not change Machine ABI 2, ABL_RNF2, Application ABI 1, Frame 1, Effect protocol 1, host behavior, capability authority, replacement count, changed-file count, or external-effect semantics. The v1.0.6 release is explicitly `praxis-successor-artifact-release/v1`: it binds application artifacts and deterministic/retry/replay/measurement proofs for downstream Poiesis use and makes no new Praxis live-execution or publication claim.
